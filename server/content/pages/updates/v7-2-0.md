# Competitive Play
## Seed Page
* Course rating and slope values added to every course
* Stroke index (HDCP) column added to the hole table
* Signed in players see their handicap for the seed

## Handicap Index
* Players can view their handicap index at [/me](/me).
* Handicap indexes are built from daily seed rounds only.
* Everyone starts at 0, with that starting value fading into the true rating as rounds are played.
* Calculated based on the best 8 of the player's last 10 dailies.

## Daily Results (On a Daily Seed's page)
* Standings by Stableford points, with ties broken by countback (back 9, then last 6, last 3, finally the 18th).
* Head-to-head match play against everyone else on the field
* A skins game across the field with carryovers.  Tied holes roll into the next one, ties at 18 stay unclaimed.
* Two players required for a daily to be scored.

## Net Scorecards
* Round pages for Daily Seeds show net scores and Stableford points
